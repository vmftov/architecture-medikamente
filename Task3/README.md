# Реестр программных и аппаратных средств защиты и контроля данных

**Хранение данных:**

- Изолированные инстансы **PostgreSQL** с Row-Level Security.
- **postgresql_anonymizer** для динамической и статической маскировки данных.
- **Postgres Pro Backup Enterprise (ProBackup)** - автоматическое создание и шифрование резервных копий БД.
- **S3** - озеро данных для хранения обезличенных данных уровней Bronze и Silver.
- **ClickHouse** для хранения золотых датасетов и аналитических отчётов.
- **HashiCorp Vault (или российские аналоги)** для хранения и ротации ключей шифрования и других секретов.

**Доступ к данным:**

- **Apache APISIX** - API Gateway для обеспечения TLS, централизованной аутентификации, проверок безопасности и Rate Limiting.
- **Keycloak с опциональным OpenLDAP** для аутентификации и авторизации по ролям и тегам.
- **Active Directory** - унаследованный сервис для авторизации внутри домена, выступает как LDAP.
- **Аппаратные ключи MFA** - физические токены двухфакторной аутентификации для бухгалтеров.
- **DLP-система** для контроля персылаемых через API и электронную почту персональных, медицинских и финансовых данных, а также блокировки вредоносных писем.

**Контроль движения данных (Data Lineage):**

- **Apache NiFi** для управления потоками данных в т.ч. валидация, обезличивание и маскировка.
- **Privacy-SPS / DataLab** для автоматического сканирования хранилищ и тэгирования данных.
- **DataHub (или российские аналоги)** - каталог метаданных для хранения тэгов и обеспечения Data Lineage.
- **Kaspersky KUMA с Elastic Stack, VictoriaMetrics** - комплексная российская SIEM система для мониторинга событий, обнаружения вторжений и оповещения службы безопасности.
- **Антивирусы и фаерволлы** для защиты компьбтеров и других устройств сотрудников от вирусов и другого вредоносного ПО.
- **Kubernetes** - создание изолированных Security Groups (сетей) для предотвращения распространения угроз в случае взлома.
